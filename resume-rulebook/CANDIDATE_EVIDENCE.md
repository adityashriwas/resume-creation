# Candidate evidence worksheet

Copy this file to `local/CANDIDATE_EVIDENCE.md` before filling it in.

## Profile and preferences
Name, contacts, target role, preferred project order, formatting preferences, and local timezone.

## Employment
Actual employer/title/dates; personally implemented features; maintenance contributions; collaborators; supported outcomes. Distinguish existing-app work from original authorship.

## Projects
For each: purpose, personal contribution, technologies used, implementation status, user benefit, source/reference, and limits. Use `local/projects/` for detailed notes.

## Skills, education and achievements
List only supported skills and accurate education/achievement details.

## Metrics and open questions
Record measurement source, baseline, period and scope for each metric. Mark estimates and unverified claims explicitly.

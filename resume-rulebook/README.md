# Role tailoring guides

Start with [shared rules](SHARED_RESUME_RULES.md), the candidate's private `local/CANDIDATE_EVIDENCE.md`, and the actual job description. The public [evidence worksheet](CANDIDATE_EVIDENCE.md) contains placeholders only.

Choose `SDE`, `Software_Developer`, `Full_Stack_Developer`, `Backend_Developer`, `Frontend_Developer`, or `Mobile_Application_Developer`, and read that folder's `RESUME_INSTRUCTIONS.md`. Resolve overlapping titles using job responsibilities. Use these guides for general editorial decisions. Evaluate job requirements against the actual target description and assess resume quality through evidence, relevance and readability.

# Shared resume rules

Use candidate-supported claims. Distinguish reported contributions from independently verified outcomes. Support metrics, skills, seniority, release ownership and production scale with evidence. When measurement is pending, describe concrete user benefits and implemented behavior.

Write a role-focused summary, relevant skills, distinct experience contributions and attributable project work. Focus the summary on responsibilities and strengths. Place technology details in skills and relevant project evidence, and give each bullet a distinct contribution. Let the substance determine each bullet's length.

Preserve the current candidate template, including margins, fonts, spacing, headings, section order and bold emphasis. Use hyphens for project points. Keep a one-page target by selecting and tightening content. Verify rendered output when building is authorized; for source-only edits, report page fit as unverified.

Use placeholders in public files. Store personal evidence, source files and outputs under ignored `local/`. Follow AGENTS.md for workflow and finalization.
